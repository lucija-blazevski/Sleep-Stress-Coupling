# REM Sleep–Distress Coupling and Anxiety Outcomes

R code accompanying a study of REM sleep, overnight distress alleviation, and subsequent anxiety outcomes.

## Repository structure

```text
00_helpers.R   Shared functions
00_tables.R    Descriptive tables
01_analysis.R  Statistical analyses and figures
```

## Requirements

The code was developed in R 4.4.2. Required packages are listed in the scripts.

## Data availability

The individual-level sleep EEG and clinical data are not included in this repository.
